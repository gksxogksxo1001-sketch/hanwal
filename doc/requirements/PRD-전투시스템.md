# PRD-04: 전투 시스템

> **프로젝트**: 한월(韓月)  
> **작성일**: 2026-05-06  
> **우선순위**: 🔴 최우선 (게임의 핵심 루프)  
> **참고 시스템**: 붕괴: 스타레일 CTB + 페르소나 약점 시스템

---

## 1. 개요

한월(韓月)의 전투는 **행동 게이지(Action Gauge) 기반 조건부 턴제(CTB)** 방식으로 진행된다. 파티 전체가 공유하는 스킬 포인트(SP) 관리와 적의 속성 약점 공략이 핵심 전략 요소이다.

---

## 2. 전투 흐름

### 2-1. 전투 진입 ~ 종료

```
[던전/레이드 진입]
    ↓
[전투 초기화]
    → 아군 4명 + 적 1~4명 배치
    → 행동 게이지 초기화 (속도 기반)
    → SP 초기 3포인트
    → 에너지 초기 0%
    ↓
[전투 루프 시작]
    → 행동 게이지 1위 캐릭터 턴 실행
    → 행동 선택 (일반공격 / 스킬 / 필살기)
    → 행동 결과 처리 (데미지, 약점격파, 버프/디버프)
    → 다음 행동 순서 갱신
    → 승리/패배 조건 체크
    ↓
[전투 종료]
    → 승리: 보상 지급 (경험치, 골드, 드랍 아이템)
    → 패배: 스태미나 일부 환급, 재도전 가능
```

### 2-2. 전투 상태 저장

| 항목 | 설명 |
|------|------|
| 저장 시점 | 매 턴 행동 완료 시 서버에 상태 저장 |
| 저장 데이터 | 각 캐릭터 HP, SP, 에너지, 행동 게이지, 적 상태, 턴 수 |
| 브라우저 닫힘 | 재접속 시 저장된 상태에서 전투 이어서 진행 |
| 비정상 종료 | 5분 이상 미행동 시 전투 자동 패배 처리 |

## 3. 핵심 전투 메커니즘

### 3-1. 행동 게이지 (Action Gauge)

```
[행동 순서 바 (Turn Order Bar)]

◀── 빠름                              느림 ──▶
┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐
│A1││E1││A2││E2││A3││E1││A4││E3│
└──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘
 ↑ 현재 턴
 
A = 아군(Ally), E = 적(Enemy)
```

| 항목 | 설명 |
|------|------|
| 게이지 충전 | 각 유닛의 SPD(속도) 스탯에 비례하여 게이지 충전 |
| 충전 공식 | `게이지 증가량 = 10000 / SPD` (SPD가 높을수록 빨리 참) |
| 행동 임계값 | 게이지가 10000에 도달하면 행동 가능 |
| 행동 후 | 게이지 0으로 초기화, 다시 충전 시작 |
| 속도 버프/디버프 | SPD 변경 시 실시간으로 게이지 충전 속도 변경 |

### 3-2. 스킬 포인트 (SP)

| 항목 | 설명 |
|------|------|
| 최대 SP | 5 포인트 (파티 공유) |
| 초기 SP | 3 포인트로 시작 |
| 회복 | 일반 공격 시 +1 SP |
| 소모 | 전투 스킬 사용 시 -1 SP (스킬에 따라 변동) |
| 전략적 의미 | "누가, 언제 스킬을 쓸 것인가"의 자원 관리 요소 |

### 3-3. 에너지 & 필살기 (Ultimate)

| 항목 | 설명 |
|------|------|
| 최대 에너지 | 캐릭터별 상이 (기본 120~180) |
| 초기 에너지 | 0에서 시작 |
| 충전 방법 | 일반공격(+20), 스킬(+30), 피격(+10), 적 처치(+15) |
| 필살기 발동 | 에너지 100% 시 **턴 순서 무시하고 즉시 발동 가능** |
| 발동 후 | 에너지 0으로 초기화 |
| 핵심 특징 | 적 턴 중에도 끼어들어 발동 가능 (인터럽트) |

### 3-4. 약점 & 강인도 (Weakness & Toughness)

| 항목 | 설명 |
|------|------|
| 적 약점 | 각 적은 1~2개의 속성 약점을 가짐 |
| 약점 표시 | 적 머리 위에 약점 속성 아이콘 표시 |
| 강인도 | 적마다 강인도(Toughness) 게이지 보유 |
| 강인도 감소 | 약점 속성으로 공격 시 강인도 감소 (비약점 시 미감소) |
| 약점 격파 | 강인도 0 → **Break 상태** 진입 |

### 3-5. Break 상태 (약점 격파)

| 효과 | 설명 |
|------|------|
| 행동 지연 | 적의 행동 게이지가 **대폭 감소** (약 50%) |
| 피해 증가 | Break 상태 동안 받는 모든 피해 **1.3배** |
| 속성 추가 데미지 | Break 시 공격 속성에 따른 추가 효과 발동 |
| 지속 시간 | 적이 다시 행동 1회 할 때까지 지속 |
| 강인도 회복 | Break 해제 후 강인도 전량 회복 |

### 속성별 Break 추가 효과

| 속성 | Break 추가 효과 |
|:----:|-----------------|
| 🔥 불 | 화상(Burn): 3턴간 매 턴 HP의 5% 지속 피해 |
| 💧 물 | 동결(Freeze): 1턴 행동 불가 |
| 🌿 바람 | 감속(Slow): 2턴간 속도 30% 감소 |
| 🪨 땅 | 방어파쇄(Shatter): 2턴간 방어력 25% 감소 |
| ⚡ 번개 | 감전(Shock): 2턴간 매 턴 HP의 3% 지속 피해 + 행동 시 추가 피해 |

## 4. 행동 선택지

### 4-1. 턴이 돌아왔을 때 선택 가능한 행동

```
┌─────────────────────────────┐
│     행동 선택 UI              │
│                              │
│  ┌──────────┐ ┌──────────┐  │
│  │ 일반 공격  │ │ 전투 스킬 │  │
│  │ SP +1    │ │ SP -1    │  │
│  └──────────┘ └──────────┘  │
│                              │
│  ┌──────────┐ ┌──────────┐  │
│  │ 필살기    │ │ 자동 전투 │  │
│  │ 에너지100%│ │ ON/OFF   │  │
│  └──────────┘ └──────────┘  │
│                              │
│      [타겟 선택 영역]          │
│  ┌────┐ ┌────┐ ┌────┐      │
│  │ 적1 │ │ 적2 │ │ 적3 │      │
│  └────┘ └────┘ └────┘      │
└─────────────────────────────┘
```

### 4-2. 자동 전투 (Auto Battle)

| 항목 | 설명 |
|------|------|
| 활성화 | 전투 중 "자동 전투" 버튼 토글 |
| AI 로직 | 약점 속성 우선 타겟 → SP 있으면 스킬 사용 → 없으면 일반 공격 |
| 필살기 | 오토 모드에서도 에너지 100% 시 자동 발동 |
| 해제 | 언제든 토글로 수동 전환 가능 |

## 6. 데미지 계산 공식

### 6-1. 기본 데미지 공식

```
기본 데미지 = (ATK * 스킬 배율) - (적 DEF * 0.5)
속성 배율 = 유리 1.5 / 보통 1.0 / 불리 0.75
치명타 배율 = CRIT 발생 시 CDMG% 적용
Break 배율 = Break 상태 시 1.3

최종 데미지 = 기본 데미지 * 속성 배율 * 치명타 배율 * Break 배율
```

### 6-2. 최소 데미지 보장

```
최종 데미지 = MAX(최종 데미지, 1)  // 최소 1의 데미지는 보장
```

## 8. API 엔드포인트 (예상)

| Method | Endpoint | 설명 |
|--------|----------|------|
| POST | `/api/battle/start` | 전투 시작 (던전 ID + 파티 정보) |
| GET | `/api/battle/state` | 현재 전투 상태 조회 |
| POST | `/api/battle/action` | 행동 실행 (공격/스킬/필살기 + 타겟) |

| GET | `/api/battle/result` | 전투 결과 및 보상 조회 |
| POST | `/api/battle/retreat` | 전투 포기 (스태미나 일부 환급) |

## 9. 예외 상황 처리

| 상황 | 처리 방안 |
|------|-----------|
| 전투 중 브라우저 닫힘 | 서버에 전투 상태 유지, 5분 내 재접속 시 이어서 진행 |
| 5분 초과 미접속 | 전투 패배 처리, 스태미나 50% 환급 |
| 행동 버튼 연타 | 서버에서 턴 순서 검증, 중복 행동 차단 |
| 비정상 행동 요청 | 죽은 캐릭터 행동, SP 부족 스킬 등 서버에서 거부 |
| 네트워크 지연 | 클라이언트 행동 버튼 비활성화 → 서버 응답 후 활성화 |
