# PRD-06: 던전 & 레이드 시스템

> **프로젝트**: 한월(韓月)  
> **작성일**: 2026-05-06  
> **우선순위**: 🔴 최우선 (핵심 콘텐츠 루프)

---

## 1. 개요

한월(韓月)의 PvE 콘텐츠는 **요일 던전**, **무한의 탑**, **스토리 던전**, **주간/월간 레이드**로 구성된다. 모든 던전 입장은 스태미나를 소모하며, 입장~보상 지급까지 트랜잭션으로 관리된다.

---

## 2. 요일 던전

### 2-1. 요일별 보상 구성

| 요일 | 던전 이름 | 속성 | 주요 보상 |
|:----:|-----------|:----:|-----------|
| 월 | 화염 수련장 | 🔥 | 불 속성 승급 재료 |
| 화 | 수류 비경 | 💧 | 물 속성 승급 재료 |
| 수 | 질풍 협곡 | 🌿 | 바람 속성 승급 재료 |
| 목 | 지맥 동굴 | 🪨 | 땅 속성 승급 재료 |
| 금 | 뇌전 봉우리 | ⚡ | 번개 속성 승급 재료 |
| 토 | 금강 성채 | 🔨 | 강화석 (전 등급) |
| 일 | 만금 보고 | 💰 | 골드 대량 획득 |

### 2-2. 난이도

| 난이도 | 권장 전투력 | 스태미나 | 보상 배율 | 해금 조건 |
|:------:|:----------:|:--------:|:---------:|-----------|
| 일반 | 1,000 | 10 | x1 | 기본 해금 |
| 어려움 | 3,000 | 15 | x2 | 일반 3성 클리어 |
| 지옥 | 8,000 | 20 | x4 | 어려움 3성 클리어 |

### 2-3. 클리어 평가 (별점)

| 별점 | 조건 |
|:----:|------|
| ⭐ | 클리어 |
| ⭐⭐ | 10턴 이내 클리어 |
| ⭐⭐⭐ | 10턴 이내 + 파티원 전원 생존 |

### 2-4. 일일 제한

- 요일 던전은 **1일 총 6회** 입장 가능 (난이도 불문)
- 00:00(서버 시간) 기준 초기화

## 3. 무한의 탑

### 3-1. 기본 규칙

| 항목 | 설명 |
|------|------|
| 구조 | 1층부터 시작, 클리어 시 다음 층 해금 |
| 층 구성 | 각 층마다 적 구성/속성 상이 |
| 스태미나 | 무소모 (무한 도전 가능) |
| 보상 | 층수 마일스톤(10층, 20층, 50층…)별 보상 + 최초 클리어 보상 |
| 초기화 | 매월 1일 00:00 기준 랭킹 초기화 (층수 기록은 유지) |

### 3-2. 마일스톤 보상 (예시)

| 층수 | 보상 |
|:----:|------|
| 10층 | 영석 100 + 강화석 x20 |
| 20층 | 영석 200 + A등급 장비 선택 상자 |
| 50층 | 영석 500 + S등급 캐릭터 뽑기권 1장 |
| 100층 | 영석 1000 + U등급 승급 재료 |
| 이후 10층마다 | 영석 50 + 강화석 x10 |

### 3-3. 특수 층 (보스 층)

- 매 10층마다 **보스 전투** (특수 기믹 포함)
- 보스는 2~3개 약점, 높은 강인도, 특수 패턴 보유
- 보스 층 클리어 시 추가 보상 지급

## 4. 스토리 던전

### 4-1. 기본 규칙

| 항목 | 설명 |
|------|------|
| 구조 | 챕터 → 스테이지 구조 (예: 1-1, 1-2, ... 1-10) |
| 스토리 | 각 스테이지 전투 전·후에 스토리 대화/컷신 삽입 |
| 해금 | 이전 스테이지 클리어 시 다음 스테이지 해금 |
| 스태미나 | 최초 클리어: 무소모 / 재도전(파밍): 스태미나 8 소모 |
| 보상 | 최초 클리어: 영석 + 경험치 / 재도전: 경험치 + 골드 + 드랍 |

### 4-2. 챕터 구성 (초기)

| 챕터 | 제목 | 스테이지 수 | 주요 이벤트 |
|:----:|------|:----------:|-------------|
| 1 | 남궁세가의 비극 | 10 | 프롤로그 후속, 수련 시작 |
| 2 | 무림맹 입문 | 10 | 마을 시설 해금, 첫 동료 합류 |
| 3 | 마교의 그림자 | 10 | 마교 간부 첫 조우 |
| ... | (확장) | ... | ... |

### 4-3. 스토리 소환/전투 가이드

- 특정 스토리 스테이지에서 **주인공(메인 캐릭터) 강제 편성**
- 주인공은 레벨/장비에 따라 성장하는 고정 파티원
- 나머지 3슬롯은 자유 편성

## 5. 레이드 시스템

### 5-1. 주간 레이드

| 항목 | 설명 |
|------|------|
| 초기화 | 매주 월요일 00:00 |
| 입장 횟수 | 주 3회 |
| 스태미나 | 30 소모 |
| 보스 | 마교 간부급 보스 (주차별 교체) |
| 보상 | A~S등급 장비, 전용무기 재료, 강화석 다량 |
| 난이도 | 일반 / 영웅 (권장 전투력에 따라 해금) |

### 5-2. 월간 레이드

| 항목 | 설명 |
|------|------|
| 초기화 | 매월 1일 00:00 |
| 입장 횟수 | 월 2회 |
| 스태미나 | 50 소모 |
| 보스 | 마교 수장급 보스 (고정 기믹, 패턴 복잡) |
| 보상 | S등급 장비, U등급 승급 재료, 전용무기 |
| 난이도 | 영웅 단일 난이도 (최상급 콘텐츠) |

### 5-3. 레이드 전투 특수 규칙

| 규칙 | 설명 |
|------|------|
| 보스 기믹 | 특정 턴마다 패턴 발동 (범위기, 무적, 소환 등) |
| 분노 게이지 | 보스 HP가 줄어들수록 공격력/속도 증가 |
| 클리어 타임 기록 | 보스 처치까지 소요 턴 수 기록 (랭킹 연동) |
| 누적 데미지 기록 | 전투 중 파티 총 딜량 기록 (랭킹 연동) |

## 6. 던전/레이드 입장 트랜잭션

```
@Transactional
던전 입장:
    1. 입장 조건 검증 (레벨, 전투력, 해금 여부)
    2. 입장 횟수 제한 확인 (일일/주간/월간)
    3. 스태미나 잔량 확인
    4. 스태미나 차감
    5. 입장 횟수 카운트 증가
    6. 전투 세션 생성
    → 실패 시 전체 롤백

@Transactional
보상 지급:
    1. 전투 결과 검증 (승리 여부)
    2. 보상 아이템 결정 (드랍 테이블 기반)
    3. 인벤토리에 아이템 추가
    4. 경험치/골드 지급
    5. 클리어 기록 업데이트
    → 실패 시 전체 롤백
```

## 7. API 엔드포인트 (예상)

|--------|----------|------|
| GET | `/api/dungeon/daily` | 오늘의 요일 던전 목록 |

| GET | `/api/story/progress` | 스토리 진행 상황 |
| POST | `/api/story/enter` | 스토리 던전 입장 |
| GET | `/api/raid/weekly` | 주간 레이드 정보 + 남은 횟수 |
| GET | `/api/raid/monthly` | 월간 레이드 정보 + 남은 횟수 |
| POST | `/api/raid/enter` | 레이드 입장 |
| GET | `/api/dungeon/rewards/{battleId}` | 던전 보상 조회/수령 |
