## 1. 프로젝트 개요 (Project Overview)

**한월(韓月)**는 웹 브라우저에서 즐기는 **무협 판타지 턴제 RPG**이다.  
다섯 원소의 기(氣)가 지배하는 한월(韓月) 대륙을 배경으로, 플레이어는 남궁세가의 막내로서 강호의 위기를 막기 위한 모험을 떠난다.

### 핵심 가치 (Core Pillars)
1. **소셜 힐링**: 다른 게임에 지쳤을 때 들어와서 유저들과 소통하며 소소하게 즐기는 공간
2. **전략적 전투**: 스타레일 CTB + 페르소나 약점 시스템 기반의 깊이 있는 턴제 전투
3. **파밍 기반 성장**: 과금 뽕맛보다는 꾸준한 플레이로 보상받는 육성 구조

## 2. 세계관 (World Setting)

### 2-1. 한월(韓月) 대륙

태초에 다섯 원소의 기(氣) — **화(火), 수(水), 풍(風), 지(地), 뇌(雷)** — 가 세상을 지탱하던 대륙.  
수백 년간 무림의 질서를 유지하던 **오대세가**와 **구대문파**가 강호를 이끌어왔다.

### 2-2. 오대세가 (五大世家)

| 세가 | 속성 | 특징 |
|------|:----:|------|
| **남궁세가** (南宮世家) | ⚡ 뇌 | 뇌전검법의 명가. 주인공의 출신 가문 |
| **제갈세가** (諸葛世家) | 🌿 풍 | 지략과 진법의 대가. 군사 가문 |
| **모용세가** (慕容世家) | 🔥 화 | 상대의 무공을 베끼는 이수환주의 가문 |
| **사천당가** (唐家) | 💧 수 | 암기와 독의 달인. 숨겨진 무기 전문 |
| **하북팽가** (四天河家) | 🪨 지 | 금강불괴 육체 수련의 가문 |

### 2-3. 구대문파 (九大門派)

> 구대문파는 향후 스토리 확장 및 NPC/던전 콘텐츠에 활용될 수 있는 세력으로,  
> 초기 버전에서는 설정만 존재하고 콘텐츠는 단계적으로 추가한다.

- 소림사, 무당파, 화산파, 개방, 아미파, 곤륜파, 점창파, 청성파, 숭산파 등  
- 각 문파는 고유한 무공 체계와 속성 성향을 가진다

### 2-4. 마교 & 천마 (天魔)

- 수백 년 전 봉인되었던 **천마(天魔)**의 마기가 다시 퍼지기 시작
- 봉인이 풀리며 고대 던전(마굴, 비경)들이 하나둘 깨어남
- 천마는 게임의 **최종 보스(Final Boss)**

## 3. 메인 스토리 (Main Story)

### 프롤로그

> 한월 대륙, 남궁세가. 오대세가 중에서도 가장 맹렬한 뇌전검법을 자랑하는 명문가 남궁세가만의 상승심법, 상승검법이 존재.
> 
> 그 막내 — **남궁○○** (플레이어 이름) — 는 모든 이가 인정하는 천재적 자질을 타고났다.  
> 그러나 타고난 게으름 탓에 수련은 뒷전, 매일 낮잠과 한가로운 나날만 보내고 있었다.
> 
> 어느 날, 평화롭던 강호에 마기(魔氣)가 퍼지기 시작한다.  
> 무림맹은 급히 **강호 최고수 8인**을 소집하여 천마 토벌대를 결성한다.  
> 남궁세가에서는 **현 가주**와 **전대가주** — 주인공의 아버지와 할아버지 — 가 출전한다.
> 
> 토벌대는 천마의 본거지에서 처절한 전투를 벌이나... **전멸**.  
> 강호 최고수 8인 중 생환한 자는 없었다.
> 
> 가주와 전대가주의 죽음 소식에 충격을 받은 남궁○○.  
> 더 이상 게으를 수 없다. 복수를 위해, 무너진 강호를 위해,  
> 마침내 검을 잡고 수련을 시작한다.
> 하지만 적들은 수련하는 시간을 기다려주지 않았고 남궁세가까지 처들어왔다.
> 남궁세가는 멸문위기에 처하고 주인공은 아끼던 호위무사의 희생으로 하인과 함께 간신히 탈출한다.
> 

### 핵심 스토리 흐름

```
[프롤로그 컷신] 
    → 남궁세가의 일상, 게으른 주인공 소개
    → 천마 출현, 토벌대 결성, 가주·전대가주 전사 소식
    → 주인공 정신차리고 수련을 시작
    → 남궁세가까지 처들어온 적들을 막기 위해 호위무사와 함께 싸우지만 역부족
    → 호위무사의 희생으로 하인과 함께 간신히 탈출
    → 탈출하는 과정에서 절벽에서 떨어짐
    → 정신을 차리고 일어나서 기연을 만나고 기본 스킬을 얻음

[튜토리얼 전투]
    → 기본 전투 시스템 학습 (약한 마물 상대로 죽을 뻔 하다가 호위무사중 한명이 도련님 or 아가씨 도망치세요하고 하인이랑 같이 도망침)
    → 도망치다가 절벽에서 떨어짐
    → 절벽에서 떨어지면서 정신을 잃고 쓰러짐
    → 정신을 차리고 일어나서 기연을 만나고 기본 스킬을 얻음

[초보자 가챠]
    → 첫 동료 획득 (기본 캐릭터 1명 확정)

[마을 도착]
    → 무림맹 본산(마을 허브) 진입
    → NPC 안내로 시설 둘러보기
    → 본격 모험 시작
```

### 캐릭터 성별 선택 & Variant 시스템

게임 시작 시 **남/여** 캐릭터를 선택할 수 있다.  
성별에 따라 **스토리 서사, 스킬 이름, 속성, 연출**이 완전히 달라지지만,  
서버(DB)단의 **시스템 로직(수치, 재화, 밸런스)은 100% 통일**된다.

#### 설계 원칙: "껍데기는 분리, 속은 통일"

| 레이어 | 남캐 (막내아들) | 여캐 (막내딸) | 통일 여부 |
|--------|----------------|---------------|:---------:|
| 스토리 텍스트 | 잃어버린 가전무공(뇌전) 수집·복원 | 타 문파(아미/북해) 무공 전수 | ❌ 분리 |
| 스킬 이름 | 뇌전일섬, 상승검법, 만뇌귀종 | 빙하참, 북해빙공, 극빙천지 | ❌ 분리 |
| 스킬 속성 | ⚡ 뇌(번개) | 💧 수(물/빙) | ❌ 분리 |
| 컷신/대사 | 아들용 대사 | 딸용 대사 | ❌ 분리 |
| 데미지 공식 | 동일 | 동일 | ✅ 통일 |
| SP/에너지 비용 | 동일 | 동일 | ✅ 통일 |
| 성장 재화 | 동일 ("무학의 조각") | 동일 ("무학의 조각") | ✅ 통일 |
| 파밍 던전 | 동일 | 동일 | ✅ 통일 |
| DB 테이블 구조 | 동일 | 동일 | ✅ 통일 |

#### 재화 표시 변환 예시
| DB (서버) | 남캐 UI | 여캐 UI |
|-----------|---------|---------|
| `mc_upgrade_fragment` | "비급의 조각 ⚡" (복원 연출) | "빙공 비전서 💧" (전수 연출) |
| `mc_skill_unlock` | "상승검법이 복원되었습니다!" | "북해빙공을 전수받았습니다!" |

> 💡 주인공은 4인 파티 중 1명이므로, 속성이 달라도 나머지 3명(가챠 캐릭)으로 상성 커버가 가능하여 밸런스 영향 미미

## 4. 타겟 사용자 프로파일 (Target Audience)

### 프라이머리 타겟: 하드코어 RPG 유저
- 전투 전략, 파티 조합, 약점 시스템 최적화에 몰입

- 가챠로 캐릭터 수집하는 재미

## 7. 캐릭터 직업군 (Character Classes)

## 8. 등급 체계

### 캐릭터 등급
```
 C (삼류) → B (일류) → A (절정) → S (초절정) → U (화경) → L (현경)
                                          │             현경은 아이디마다 한 캐릭식의 U등급의 캐릭터만 승급가능
                                     특수 재료 파밍으로   업적 보상으로 받아서 가능함.
                                       승급 가능
```

### 장비 등급
```
 C (일반) → B (고급) → A (희귀) → S (전설)
   │          │          │          │
   강화만    강화만     강화만     강화만
   가능      가능       가능       가능
   (등급 변경 불가)
```

## 9. 기술 스택 & 아키텍처 방향

| 레이어 | 기술 | 비고 |
|--------|------|------|
| **Backend** | Spring Boot 3.x | REST API, WebSocket |
| **Database** | MySQL | 게임 데이터, 유저 데이터 |
| **Frontend** | HTML + Thymeleaf | 초기 레이아웃 렌더링 |
| **CSS** | Tailwind CSS | 모던 UI 스타일링 |
| **상태관리** | Alpine.js | 클라이언트 사이드 실시간 데이터 |
| **통신** | Fetch API + WebSocket | 비동기 게임 액션 + 실시간 채팅 |
| **아이콘** | Lucide Icons | UI 아이콘 |
| **차트** | Chart.js | 스탯/전투 로그 시각화 |

### Headless 아키텍처
- 컨트롤러는 JSON 데이터만 반환
- Thymeleaf는 초기 레이아웃만 담당
- 모든 게임 로직은 비동기 API 호출
- 향후 Unity/Three.js 등 3D 클라이언트로 교체 가능
