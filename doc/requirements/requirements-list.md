## 6. 전투 시스템 (CTB 기반)

| ID | 요구사항 | 우선순위 |
|----|----------|:--------:|
| BTL-001 | 전투는 행동 게이지(Action Gauge) 기반의 조건부 턴제(CTB) 방식으로 진행된다. | 🔴 필수 |
| BTL-002 | 캐릭터의 '속도' 스탯에 따라 행동 게이지 충전 속도가 결정되고, 게이지가 찬 순서대로 행동한다. | 🔴 필수 |
| BTL-003 | 전투 화면 상단에 행동 순서 바(Turn Order Bar)가 표시되어, 아군과 적의 행동 순서를 미리 확인할 수 있다. | 🔴 필수 |
| BTL-004 | 파티 전체가 공유하는 스킬 포인트(SP) 시스템이 존재한다. 일반 공격 시 SP가 회복되고, 전투 스킬 사용 시 SP가 소모된다. | 🔴 필수 |
| BTL-005 | 각 캐릭터는 에너지를 충전하여 필살기(Ultimate)를 사용할 수 있으며, 필살기는 현재 턴 순서를 무시하고 즉시 발동할 수 있다. | 🔴 필수 |
| BTL-006 | 적은 1~2개의 속성 약점을 가지며, 약점 속성으로 공격 시 강인도(Toughness)가 감소한다. | 🔴 필수 |
| BTL-007 | 적의 강인도가 0이 되면 '약점 격파(Break)' 상태가 되어 행동이 지연되고 받는 피해가 증가한다. | 🔴 필수 |
| BTL-008 | 전투 중 자동 전투(Auto Battle) 모드를 활성화하여 AI가 자동으로 행동을 선택하게 할 수 있다. | 🟡 권장 |
| BTL-009 | 전투 결과(승리/패배)에 따라 경험치, 골드, 아이템 등의 보상이 지급된다. | 🔴 필수 |
| BTL-010 | 전투 상태(턴 정보, HP 등)는 서버에 저장되어, 브라우저를 닫아도 진행 상황이 유지된다. | 🔴 필수 |
