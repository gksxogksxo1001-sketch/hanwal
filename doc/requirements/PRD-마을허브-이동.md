# PRD-02: 마을 허브 & 이동 시스템

> **프로젝트**: 한월(韓月)  
> **작성일**: 2026-05-06  
> **우선순위**: 🔴 최우선 (게임의 중심 공간)

---

## 1. 개요

무림맹 본산을 배경으로 한 **마을 허브**는 한월(韓月)의 중심 공간이다. 플레이어는 8방향(WASD + 대각선)으로 이동하며, 각 시설에 접근하여 상호작용한다. 마을은 자유 탐험이 아닌 **허브형 구조**로, 시설 간 이동과 각종 콘텐츠 진입점 역할을 한다.

## 3. 이동 시스템

### 3-1. 8방향 이동

| 입력 | 방향 | 이동 벡터 |
|------|:----:|:---------:|
| W | ↑ 상 | (0, -1) |
| S | ↓ 하 | (0, +1) |
| A | ← 좌 | (-1, 0) |
| D | → 우 | (+1, 0) |
| W + A | ↖ 좌상 | (-1, -1) 정규화 |
| W + D | ↗ 우상 | (+1, -1) 정규화 |
| S + A | ↙ 좌하 | (-1, +1) 정규화 |
| S + D | ↘ 우하 | (+1, +1) 정규화 |

### 3-2. 이동 방식

| 항목 | 설명 |
|------|------|
| **방식** | 픽셀(좌표) 기반 자유 이동 (젤다 스타일) |
| **속도** | 일정한 이동 속도 (달리기/걷기 구분 없음, 초기 버전) |
| **대각선 보정** | 대각선 이동 시 벡터 정규화로 속도 균일 유지 |
| **충돌 판정** | 맵 경계, 건물 벽 등 충돌 시 이동 불가 |
| **캐릭터 표현** | 2D 스프라이트 (방향별 이동 애니메이션) |

### 3-3. 트리거 영역 (Trigger Area)

- 시설 근처에 **투명 트리거 영역** 설정
- 캐릭터가 영역에 진입하면 **상호작용 버튼(E키)** 안내 표시
- E키 입력 시 해당 시설의 UI 팝업이 열림
- 영역을 벗어나면 안내 표시 사라짐

```
[캐릭터 트리거 영역 진입]
    → "space키를 눌러 상호작용" 안내 표시
    → space키 입력
    → 해당 시설 UI 팝업 오픈
    → ESC 또는 닫기 버튼으로 UI 닫기
    → 마을 맵으로 복귀
```

## 4. 서버 동기화

### 4-1. 위치 동기화 정책

| 항목 | 설명 |
|------|------|
| **위치 저장** | 클라이언트에서 이동 → 서버에 주기적(1초 간격) 위치 업데이트 |
| **재접속 시** | 서버에 저장된 마지막 위치에서 시작 |
| **핵 방지** | 서버에서 이동 거리/속도 검증 (비정상 이동 시 롤백) |

### 4-2. 이동 변조 방지

```
[클라이언트]                    [서버]
    │                            │
    │  위치 업데이트 요청          │
    │  {x: 150, y: 200,          │
    │   timestamp: 1234567890}   │
    │  ──────────────────────▶   │
    │                            │  1. 이전 위치와 비교
    │                            │  2. 경과 시간 대비 이동 거리 계산
    │                            │  3. 이동 속도 > 최대치? → 비정상
    │                            │  4. 벽/경계 충돌 체크
    │                            │
    │  정상: 위치 저장 확인        │
    │  ◀──────────────────────   │
    │  비정상: 이전 위치로 롤백    │
    │  ◀──────────────────────   │
```

## 5. 화면 UI 구성

### 5-1. 마을 맵 화면 레이아웃

```
┌─────────────────────────────────────────┐
│ [미니맵]              [골드] [영석] [스태]│  ← 상단 HUD
├─────────────────────────────────────────┤
│                                         │
│                                         │
│            게임 캔버스(Canvas)            │  ← 메인 영역
│         (마을 맵 + 캐릭터 렌더링)         │
│                                         │
│                                         │
├─────────────────────────────────────────┤
│ [캐릭터] [파티] [인벤] [설정]  [채팅입력] │  ← 하단 메뉴
└─────────────────────────────────────────┘
```

### 5-2. UI 요소

| 영역 | 구성 요소 | 설명 |
|------|-----------|------|
| 상단 HUD | 미니맵, 재화 표시 | 현재 위치, 골드/영석/스태미나 수치 |
| 메인 캔버스 | 마을 맵, 캐릭터, NPC | HTML5 Canvas 또는 CSS 기반 렌더링 |
| 하단 메뉴 | 퀵 메뉴 버튼 | 캐릭터, 파티편성, 인벤토리, 설정 |
| 채팅 | 채팅 입력창 | 하단 또는 우측 슬라이드 채팅 패널 |
