# PRD-09: 랭킹 시스템

> **프로젝트**: 한월(韓月)  
> **작성일**: 2026-05-06  
> **우선순위**: 🔴 필수

---

## 1. 개요

한월(韓月)의 랭킹 시스템은 **무한의 탑 랭킹**, **레이드 랭킹**, **전투력 랭킹** 3종으로 구성되며, 하드코어 유저의 경쟁 동기를 부여하고 상위 랭커에게 보상을 지급한다.

---

## 2. 랭킹 종류

### 2-1. 무한의 탑 랭킹 🏆

| 항목 | 설명 |
|------|------|
| 기준 | 도달 최고 층수 (동순위 시 클리어 시간 빠른 순) |
| 갱신 주기 | 실시간 (클리어 즉시 반영) |
| 초기화 | 매월 1일 00:00 (기록은 유지, 랭킹만 리셋) |
| 표시 정보 | 순위, 닉네임, 최고 층수, 사용 파티 구성 |

### 2-2. 레이드 랭킹 ⚔️

| 항목 | 설명 |
|------|------|
| 기준 (주간) | 주간 레이드 보스 클리어 타임 (빠른 순) |
| 기준 (월간) | 월간 레이드 누적 데미지 (높은 순) |
| 갱신 주기 | 레이드 완료 시 반영 |
| 초기화 | 주간: 매주 월요일 / 월간: 매월 1일 |
| 표시 정보 | 순위, 닉네임, 클리어 타임 or 누적 데미지, 사용 파티 |

### 2-3. 전투력 랭킹 💪

| 항목 | 설명 |
|------|------|
| 기준 | 유저의 종합 전투력 (보유 캐릭터 + 장비 합산) |
| 갱신 주기 | 1시간 단위 갱신 (서버 부하 방지) |
| 초기화 | 없음 (누적 랭킹) |
| 표시 정보 | 순위, 닉네임, 전투력, 대표 캐릭터 |

### 전투력 계산 공식

```
유저 전투력 = 파티 슬롯 1~4 캐릭터 전투력의 합

캐릭터 전투력 = (HP/10) + (ATK*2) + (DEF*1.5) + (SPD*3) 
              + 장비 보정 + 등급 보정 + 강화 보정

등급 보정: C=0, B=100, A=300, S=500, U=1000
```

## 3. 랭킹 보상

### 3-1. 무한의 탑 월간 보상

| 순위 | 보상 |
|:----:|------|
| 1위 | 영석 3,000 + U등급 승급 재료 x3 + 전용 칭호 "탑의 지배자" |
| 2~5위 | 영석 2,000 + U등급 승급 재료 x2 |
| 6~20위 | 영석 1,000 + S등급 장비 선택 상자 |
| 21~50위 | 영석 500 + A등급 장비 선택 상자 |
| 51~100위 | 영석 200 + 강화석 x50 |

### 3-2. 레이드 주간/월간 보상

| 순위 | 주간 보상 | 월간 보상 |
|:----:|-----------|-----------|
| 1~3위 | 영석 500 + 전용무기 재료 x2 | 영석 2,000 + U등급 승급 재료 x2 |
| 4~10위 | 영석 300 + 강화석 x30 | 영석 1,000 + S등급 장비 상자 |
| 11~50위 | 영석 100 + 강화석 x15 | 영석 500 + 강화석 x50 |

### 3-3. 전투력 랭킹 보상

- 전투력 랭킹은 **보상 없이 명예 랭킹**으로 운영
- 상위 10위 유저에게 **전용 칭호** 부여 (매주 갱신)
  - 1위: "강호제일인(江湖第一人)"
  - 2~3위: "절대고수(絕對高手)"
  - 4~10위: "무림십대고수(武林至尊)"

## 6. 데이터베이스 테이블 (예상)

### rankings (랭킹 기록)
```sql
CREATE TABLE rankings (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    ranking_type ENUM('TOWER','RAID_WEEKLY','RAID_MONTHLY','POWER') NOT NULL,
    record_value BIGINT NOT NULL,  -- 층수, 클리어타임(초), 데미지, 전투력
    season_id INT NOT NULL,  -- 시즌(월/주) 구분
    party_snapshot JSON,  -- 사용 파티 구성 스냅샷
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id),
    UNIQUE KEY (user_id, ranking_type, season_id)
);
```

### ranking_rewards (랭킹 보상 이력)
```sql
CREATE TABLE ranking_rewards (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    ranking_type ENUM('TOWER','RAID_WEEKLY','RAID_MONTHLY') NOT NULL,
    season_id INT NOT NULL,
    final_rank INT NOT NULL,
    rewards_claimed BOOLEAN DEFAULT FALSE,
    claimed_at DATETIME DEFAULT NULL,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```
